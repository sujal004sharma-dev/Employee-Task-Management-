# Employee Management System

A modern Employee Management System built using React.js.  
This project helps manage employees, tasks, and admin operations through a clean and responsive dashboard interface.

---

## 🚀 Features

- Employee Login & Admin Login
- Task Assignment System
- Active, Completed & Failed Task Tracking
- Responsive UI using Tailwind CSS
- Dynamic Task Cards
- Context API for State Management
- Local Storage Support
- Clean Dashboard Interface

---

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- Context API
- Local Storage
